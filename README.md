# Lista de Compras (Primeiro Contato com JavaScript)

## Como executar
Dê um duplo clique no arquivo `index.html` para abrir no navegador e pressione **F12** (aba **Console**) para acompanhar os testes.

## Roteiro de Exercícios (Tempos 3 e 4)
1. **Base:** Ler nome e preço, adicionar no array `itens`, listar no `<ul>` e somar o total.
2. **Validação:** Impedir nome vazio ou preço menor ou igual a zero, exibindo aviso em `#mensagem`.
3. **Alerta de Orçamento:** Se o total passar de R$ 100, mudar `#status-orcamento` para "Orçamento estourado!" e aplicar a classe `.alerta`.
4. **Contador e Saldo:** Atualizar `#qtd-itens` (`itens.length`) e `#saldo` (`LIMITE - total`).
5. **Limpar Tudo:** Conectar `#btn-limpar` para esvaziar o array e atualizar a tela.
